## 保留的边界与未验收项

- 充电仍为现有演示系统：电池默认60 kWh，电量由服务端模拟订单推导，未接入真实车辆遥测；车型、头像保存于本机，尚无跨设备车辆绑定或头像上传。
- 提现仅为演示钱包账本操作，不向银行转账。付款确认采用“确认停止并支付”，没有增加独立“待支付”订单状态；自动到上限或余额耗尽继续按既有预付费规则自动结算。
- 自动定位依赖运行环境。远程沙箱没有用户设备定位时，可使用城市或地图选点；导航尝试系统浏览器，打不开时显示可复制的路线链接。未验收真实GPS、地址地理编码及外部道路导航服务。
- UrbanEV 地址是数据集来源/区域信息，不是经街道核验的真实地址；新增城市站点也明确标为模拟。未编造真实营业地址。
- 站点收费仍按现有固定单价；历史分时价格不是当前计费标准，本次未新增峰谷计费策略。
- Windows 未构建或运行；本次验收为 Linux Qt 6.5.3。旧交付压缩包不代表本次运行版本。
