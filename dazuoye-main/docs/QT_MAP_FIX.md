# 原生地图修复与视觉细节（2026-09-07）

## 原因与处理

旧 ArtWidget 地图固定经度跨度 .085°，只有按下选点处理，没有滚轮、拖动或适配视野。经纬度线性映射也没有墨卡托纬度投影。路网仅覆盖深圳，但真实站点还包含上海两个站点。管理首页另外使用静态路线示意。这些是实现缺失，不是 Qt 框架无法支持地图。

用共享 C++ StationMap 控件替换两端地图及管理首页示意线路，移除旧地图绘制分支。新控件使用 Web Mercator 投影、当前城市站点适配、鼠标拖动、锚点滚轮缩放、原生缩放/居中/全部站点按钮、准确点选、比例尺、站点数、分级道路和选中气泡。只有点击释放才选择站点，拖动不触发详情。缺坐标的数据不画在零点。

深圳路网继续复用已有 OSM 资源。补充上海两个站点附近 121.38–121.58 E / 31.15–31.30 N 的 8,882 条主干/次干/三级道路；资源只覆盖注明的范围，超出范围显示离线路网提示，站点坐标仍可查看。程序不依赖在线地图服务，不提供驾驶路线计算。

上海数据来源为 OpenStreetMap Overpass API，获取脚本 scripts/fetch_qt_shanghai_roads.py。资源为 ODbL，地图持续显示 © OpenStreetMap contributors。

同时补齐原 Web 已有的 Noto Sans SC 600 字重文件，并恢复管理界面的标题层级、品牌标记、圆形按钮、图表渐变点、分组图例和带缩略图/接口/价格的站点列表。管理员站点接口没有 available_count，空闲数由已获取的电桩状态统计，未取得电桩快照时不默认为零。

## 验证

保留旧地图失败复现：.runtime/qt-map-fix/before-tests.log，拖动和滚轮两项失败。新 desktop/tests/test_map.cpp 检查当前城市适配、上海底图覆盖、缺坐标过滤、全部站点适配、缩放锚点、点击信号、滚轮缩放，以及拖动不误选。运行 test-map -platform offscreen，4 个测试用例通过（加初始化/清理合计 6 项）。

两端 Linux 编译及原生窗口截图检查完成。没有重新进行完整业务验收，也未验证 Windows。Qt 原生版仍不能宣称与参考图像素一致。
