# Qt 原生页面重构 · 2026-09-07

沿用现有网页的车辆、能量环、字体和 SVG 图标资源，在 C++17 / Qt 6.5.3 Widgets 中重建布局及交互。最新地图区域使用 WebEngine / Leaflet 在线地图，详见 QT_ONLINE_MAP.md；其他页面仍由原生 Qt 实现。服务端继续使用 FastAPI；本次不修改模型或业务数据库结构。

| 页面 | 原生实现 |
| --- | --- |
| 用户首页 | 车辆裁切、电池、续航、站点入口及底部导航 |
| 地图 | StationMap 实际站点坐标、搜索、拖动缩放、选点与详情卡 |
| 站点详情 | 双充电模式、俯视车图、限额预览、电桩选择及预约 |
| 充电中 | 紫色面板、能量环、真实订单费用、电量及启停操作 |
| 充电统计 | 历史月份/全部历史/个人账单切换、分组柱图和横向指标 |
| 用电时段 | 24 小时历史价格、低谷/高峰筛选及色带 |
| 订单历史 | 状态筛选、详情及订单操作 |
| 用户账户 | 钱包、充值、账本、资料及服务入口 |
| 管理总览 | 车辆选择、目标刻度、统计流带、状态环图与站点地图 |
| 管理站点 | 原生站点地图、选择和业务管理 |
| 管理订单 | 行程示意、状态环图、能量走势、筛选列表和运营指标 |
| 操作审计 | 日期分组时间线、类别分布、7×24 热力图、每日走势及详情 |
| 负荷预测 | 保留真实历史与模型预测图表及区间控制 |

主要代码：`desktop/src/user_window.cpp`、`admin_window.cpp` 管理页面与异步操作；`visuals.cpp` 实现分段选择器、分组柱图、趋势、热力图和路线示意；`ui.cpp` 实现公共主题和中文详情表单。`desktop/assets/web-ui.json` 从既有 `static/admin.js` 提取图标路径与字段名，供 Qt SVG 渲染。统计配色和布局参照 `static/mobile-reference.js`，订单/审计布局参照 `static/admin-activity.js`。

统计独立使用只读演示会话获取 UrbanEV 历史，不替换用户的交易身份。历史电价不代表当前站点报价。车辆电量/续航预览为展示值；真实订单零值保持为零。管理订单中的行程图已标注“行程示意”，不作为驾驶路线；站点地图仍使用真实站点坐标，路网覆盖范围见 QT_MAP_FIX.md。
