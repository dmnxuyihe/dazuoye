# Qt 遗留问题补齐交付 · 2026-09-08

本次按作业演示范围完成代码补齐。提现采用用户确认的“申请、审核、模拟到账及流水”。银行支付、真实车辆 BMS 不在本次交付范围。

## 用户端验收入口

| 遗留问题 | 实现及操作 |
| --- | --- |
| 缺定位、导航、地址搜索、距离筛选 | 找桩页可选择城市、手动选点或解析地址，搜索结果按距离显示，并与名称/地址和 5/10/50 km 范围组合筛选；点击规划路线在图内展示真实道路路径、距离、预计时间及步骤。 |
| 网页预览无法取得访问者设备位置 | 预览顶部“使用设备位置”，明确同意共享后把浏览器位置发送给 Qt；在 60 秒内打开地图即可接收。定位拒绝/不支持时使用地址或手动选点。 |
| 停充直接扣款、没有账单确认 | 停充后进入待支付，锁定明细和金额、释放电桩；“确认支付”二次确认后扣款。自动达到上限/余额用尽也进入待支付，订单历史提供待支付筛选。 |
| 分时页面和实际费用不一致 | 统一计费支持电费与服务费，按北京时间跨时段拆账；预约冻结价格，调价不回改旧单。接口页显示费用区间并可查看分时表，充电页可查明细。 |
| 车辆、头像仅本地设置 | 我的 → 车辆绑定与电量 / 更换头像，服务器持久化，换客户端登录可读；车牌不能重复绑定，有未完成订单时禁止改车。SOC 按订单模拟更新并保存。 |
| 提现无完整流程 | 我的 → 申请提现 → 提现进度；申请冻结金额，管理员审核通过模拟到账并记账，驳回解冻；钱包展示总余额、冻结与可用余额。 |
| 统计月度与历史含义混乱 | 统计只显示个人账单，按北京时间付款日期读取全量订单，支持本月/全部；待支付不计已支付费用。 |
| 电量、费用布局和导航 | 电量与费用置于独立框格；保留底部导航，展示预约倒计时、接口状态、预计到达上限时间；初始未绑定状态明确展示。 |

“经济模式”优先慢充，“快速充电”筛选快充；费用始终由实际站点分时价确定，模式不制造额外折扣。

## 管理端验收入口

- 底部“提现审核”：待审、到账、驳回分类，审核意见和模拟流水可追溯；重复审核不重复扣款。
- 站点管理选中一行即可在下方查看该站全部电桩状态；“分时价格”配置连续覆盖 0–24 点的时段，含峰谷示例。
- “解析附近地址”按坐标获取附近地址，核对后保存。UrbanEV 原始数据没有可靠门牌地址，保留数据来源说明，不将推断写成真实门牌。
- 电桩管理可组合筛选站点、状态、快慢充和功率上下限；新增选择站点并自动生成编号。
- 订单页提高上部区域最小高度，点击订单详情更新“所选订单”；去掉底部重复订单入口，新增入口保留在订单页。
- 营收及审计日期按北京时间；营收只计完成付款的订单。已有登录锁定、退出登录、用户流水表格、设备状态总览和销售分析修复保留。
