# 弹窗关闭修复 · 2026-09-08

公网运行环境只有 Xvfb/x11vnc，没有提供系统标题栏的窗口管理器。旧弹窗依赖系统关闭按钮，导致运营数据管理、钱包流水和登录/编辑表单无法通过鼠标退出。

在 ui.cpp 中统一提供 dialogHeader：标题右侧固定“× 关闭”，位于表格/滚动内容之外；点击执行 QDialog::reject，保留 Esc 退出。关闭按钮不充当默认提交按钮，也不提交表单。运营管理、钱包流水、详情、编辑表单、用户登录、管理员登录六处自定义弹窗全部接入。系统确认/错误弹窗及文件选择器已有确认/取消操作，不改变其语义。

定向回归测试通过隔离接口打开运营管理、空钱包、详情、编辑表单，检查关闭按钮可见并位于窗口内、点击发出 rejected；另检查 Esc 关闭以及整个过程中没有发出业务写请求。Linux 已编译。未运行完整生产业务验收，Windows 未验证。
