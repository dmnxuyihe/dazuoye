# 项目需求与完成度

本说明依据 `assignment_0/01-需求规格说明书.md` 整理，只保留验收时需要快速查看的范围和结论。

## 需求概述

项目提供电动汽车充电桩的用户端、管理端、数据库服务、Web 可视化大屏和负荷预测功能。用户端支持登录、找站、查看电桩、预约充电、计费结算、钱包和订单；管理端支持用户、站点、电桩、订单、统计、审计和负荷预测；服务端负责权限、事务、数据一致性和 WebSocket 刷新。
